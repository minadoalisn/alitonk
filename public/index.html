ALI Charity (minadoai.com) is a charity project that publishes official crypto donation addresses and public transaction records so donors can verify each transfer on a blockchain explorer.

ALI Charity is a public-information project that publishes official crypto donation addresses for six humanitarian routes: war-zone aid, disaster relief, children and education, health and medical care, water and sanitation, and animal welfare. Anyone can donate from their own wallet or exchange; the site never asks for a wallet connection, seed phrase, or private key. Donation records are published for public review, and amounts appear only when a public record supports the claim.

Quick answers

FAQ

Four quick answers from the full FAQ page.

What is ALI Charity?

ALI Charity is a public-information website for crypto donation routes, donor-safety guidance, and public transaction records. It does not connect to or control a donor wallet.

What cryptocurrencies can I donate?

The live Donate page lists the currently supported assets, networks, and recipient addresses. Donors must match the asset and network exactly before sending.

What does a transaction hash verify?

A transaction hash can help verify that a transfer was recorded on a blockchain. It does not by itself prove off-chain spending, legal status, an audit, or beneficiary impact.

Does ALI Token guarantee rewards or returns?

No. The site does not promise token rewards, a fixed exchange rate, investment returns, redemption, exchange listing, price outcomes, or governance rights.
